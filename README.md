# Hamza personal portfolio

Run `npm run dev`, then open http://127.0.0.1:3000/.

- index.html: personal introduction and featured QPay project.
- about.html: provisional biography and approach.
- projects.html: project overview with a real app screenshot.
- contact.html: local inquiry composer; copies text, does not send messages.
- qpay.html: retained QPay landing page, simulator and APK download.

Personal pages use personal.css and personal.js. Product pages retain app.js,
styles.css and designs.css. The website/ Git checkout contains the matching
static deployment files. No deployment was performed for this redesign.

Name, biography and contact destinations are provisional for design review.
